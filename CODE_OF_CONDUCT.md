# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Report unacceptable behavior to the maintainer through a private
[security advisory](../../security/advisories/new), or by email to the address on the maintainer's GitHub
profile.
